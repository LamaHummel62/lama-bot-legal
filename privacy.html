2. Information We May Process

Lama Bot uses a modular system. The information processed depends on which modules are enabled on a Discord server and which features are used.

  • Relevant Discord roles and permissions

Moderation Information

  • Warnings
  • Warning reasons
  • Moderator IDs
  • Moderation actions
  • Timeout, kick and ban information
  • Timestamps
  • Other relevant moderation records

Economy Information

  • Virtual wallet and bank balances
  • Economy transactions
  • Jobs and progression
  • Economy XP and levels
  • Inventory items
  • Shop purchases
  • Boosters and mystery boxes
  • Achievements
  • Quests
  • Economy events and progress
Lama Bot virtual currency and virtual items have no real-world monetary value unless explicitly stated otherwise.

Leveling Information

  • XP
  • Levels
  • Activity information required to calculate XP
  • Level rewards
  • Leaderboard information

Ticket Information

  • Ticket creator Discord ID
  • Ticket participants
  • Ticket channel information
  • Ticket status
  • Staff actions
  • Messages or content required for ticket transcripts

Server Configuration

  • Enabled modules
  • Welcome and goodbye settings
  • Auto-role configuration
  • Logging configuration
  • Verification configuration
  • AutoMod configuration
  • Ticket configuration
  • Economy configuration
  • Leveling configuration

  • Other server-specific Lama Bot settings

Technical Information

For security, reliability and debugging, Lama Bot may process limited technical information including:

  • Command usage
  • Error information
  • Timestamps
  • Server and user identifiers related to errors
  • Feature or module information
  • Application performance information

We do not intentionally collect Discord account passwords, ordinary users' Discord authentication tokens, payment card details or private credentials.

3. Message Content

Lama Bot does not intentionally store or analyze all message content without a functional reason.

Certain enabled features may require message content to be processed, including:

  • AutoMod
  • Anti-Spam
  • Anti-Link
  • Leveling or activity features
  • Ticket transcripts
  • AI commands
  • Message-based security and moderation features

Lama Bot aims to process only the information reasonably necessary for the requested or configured functionality.

Processing message content does not necessarily mean that the content is permanently stored.

4. Artificial Intelligence Features

Lama Bot provides optional AI-powered functionality using OpenAI.

AI functionality may include commands such as:

  • /ask
  • /chat
  • /summarize

When users interact with these features, information submitted to the AI feature may be transmitted to OpenAI for processing.

This may include:

  • Prompts
  • Questions
  • Text submitted for summarization
  • Relevant conversation context
  • Other content intentionally submitted to an AI feature
Important: Users should not submit passwords, authentication tokens, private keys, payment information, highly sensitive personal information or confidential information through Lama Bot's AI features.

OpenAI independently processes information according to its applicable terms, privacy policies and data-processing practices.

7. Data Storage

Lama Bot primarily stores persistent application data on infrastructure operated or controlled by the Lama Bot Project.

The Lama Bot database is hosted on our own server infrastructure.

Reasonable technical and organizational measures are used to protect stored information against unauthorized access, loss, misuse or alteration.

However, no online service or storage system can guarantee absolute security.

8. Data Retention

Lama Bot aims to retain information only for as long as reasonably necessary for its intended purpose.

Server Configuration

Stored while required to provide Lama Bot functionality, until configuration is reset, associated data is deleted, or a valid deletion request is fulfilled.

Economy & Leveling

Stored until reset, deleted, no longer required, or a valid deletion request is fulfilled.

Moderation Records

Stored until removed by authorized server staff, deleted as part of server data removal, or otherwise no longer required.

Tickets & Transcripts

Stored according to the ticket functionality and server configuration until deleted or no longer required.

Technical Logs

Technical logs are normally retained for no longer than 30 days.

Logs may be retained longer where reasonably necessary to investigate abuse, security incidents or technical problems, or where required by law.

AI Content

Lama Bot aims not to retain AI request content longer than necessary to provide the relevant feature, except where conversation history or another explicitly enabled feature requires storage.

Backups may temporarily contain previously deleted information until the applicable backup is rotated or deleted.
