Ist Lamas Wächter wirklich kostenlos?+

Ja. Die aktuell angebotenen Bot-Funktionen sind kostenlos und benötigen kein Premium-Abo.

Kann ich nur einzelne Module verwenden?+

Ja. Welche Module aktiv sind, lässt sich über die Serververwaltung einstellen.

Wie füge ich den Bot hinzu?+

Klicke auf „Bot hinzufügen“, wähle deinen Discord-Server und bestätige die erforderlichen Berechtigungen.

Wo werden die Bot-Daten gespeichert?+

Die primäre Bot-Datenbank wird auf einem privat betriebenen Server in Deutschland verwaltet. Die öffentliche Website wird über GitHub Pages ausgeliefert. Details stehen in der Datenschutzerklärung.

Wie bekomme ich Hilfe?+

Nutze /bugreport für Fehler und Supportfragen oder kontaktiere Lama_stein per E-Mail.
